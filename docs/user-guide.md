# 安装、账户与更新

## 安装 Orbit

安装包发布后，在本仓库的 **Releases** 页面下载对应版本。系统要求见发布说明。

| 电脑 | 安装方式 |
| --- | --- |
| 搭载 Apple 芯片的 Mac，运行 macOS 15 或更新版本 | 打开安装包，将 Orbit 放入「应用程序」。ZIP 文件需先解压。 |
| Windows x64 电脑 | 打开安装程序，按提示完成安装。 |

配置桌面工具前，请核对适用范围。 [接入兼容性](../README.md#兼容性)

## 登录和查看用量

1. 在首页选择「连接账户」，在浏览器中登录 Orivelle 并授权。
2. 回到 Orbit，在首页查看余额或可用预算。点击窗口顶部的「刷新」可更新账户信息。

## 退出或管理连接

- **退出登录**可在「设置」的「安全存储」中操作。退出后仍可使用有效的配置备份。 [恢复原有配置](../README.md#恢复原有配置)
- **删除本地连接**位于「接入」页。删除后，该账户的本地图片历史和配置备份会保留。
- **撤销本安装推理 key**也位于「接入」页。此操作会使该账户在本机用于桌面工具和图片任务的凭据失效。已提交的请求仍可能计费。

使用「忘记此安装」后，此安装的旧配置备份将无法恢复。

## 检查更新

在「设置」的「更新」中选择「检查更新」。应用内更新可用时，选择「下载并验证」，等当前任务结束后再确认「安装并重启」。也可开启「启动时检查更新」。

手动更新时，从 **Releases** 下载对应的安装包，按发布说明安装。

## 调整设置和获取帮助

在「设置」可调整主题、语言、图片磁盘和预览缓存上限。图片空间达到上限时，Orbit 会暂停接收新任务。可先另存需要保留的图片，再清理本地历史。

遇到问题时，请记录 Orbit 版本、操作系统和界面提示。需要诊断报告时，可在「设置」的「诊断」中预览并保存。
