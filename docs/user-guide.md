# 安装、账户与更新

## 安装 Orbit

安装包发布后，请在本仓库的 **Releases** 页面选择你的系统，并查看该版本的发布说明。

| 电脑 | 安装方式 |
| --- | --- |
| 搭载 Apple 芯片的 Mac，运行 macOS 15 或更新版本 | 打开安装包，将 Orbit 放入「应用程序」。如果下载的是 ZIP 文件，请先解压。 |
| Windows x64 电脑 | 打开 Windows 安装程序，按提示完成安装。系统版本要求见对应版本的发布说明。 |

如果想让 Orbit 配置 Codex 或 Claude Desktop，请先核对这些应用的[兼容版本](desktop-configuration.md#兼容性)。

## 登录和查看用量

1. 打开 Orbit，在首页选择「连接账户」。
2. 在打开的浏览器中登录 Orivelle，核对账户并确认授权。
3. 回到 Orbit。在首页查看账户余额或可用预算。需要更新账户信息时，点击窗口顶部的「刷新」。

登录使用你的 Orivelle 账户。账户权限决定可用的节点、模型和操作。如果只能查看用量，请联系账户管理员确认使用权限。

## 退出或管理连接

- **退出登录**可在「设置」的「安全存储」中操作。退出后，Orbit 清理当前账户在本机的登录和接入凭据，并保留本地配置备份。需要还原桌面工具时，可按[恢复原有配置](desktop-configuration.md#恢复原有配置)操作。
- **删除本地连接**位于「接入」页。它移除此连接在 Orbit 的登录信息和接入凭据，已保存的本地历史和可恢复的配置备份会保留。
- **撤销本安装推理 key**也位于「接入」页。它会停用当前账户为本机 Orbit 提供的服务凭据，影响相应的桌面接入和图片任务。已提交的请求仍可能完成并计费。

Orbit 使用系统安全存储保护登录信息和配置备份所需的密钥。「忘记此安装」会删除安装身份和对应的备份密钥，相关旧备份此后无法恢复。

## 检查更新

打开「设置」中的「更新」，选择「检查更新」。如果当前版本提供应用内安装，发现新版本后可选择「下载并验证」，等正在进行的任务结束后再确认「安装并重启」。「启动时检查更新」只负责检查，安装仍需你确认。

如果更新渠道未配置，或当前平台需手动安装，请到 **Releases** 页面获取适合你的新版本，再按发布说明安装。

## 调整设置和获取帮助

在「设置」可以切换主题和语言，调整图片磁盘和预览缓存的限额。图片空间达到上限时，Orbit 会暂停接收新任务。你可以先另存为，再删除自己选中的本地图片。

遇到问题时，请记录 Orbit 版本、操作系统及界面提示。「设置」的「诊断」可以预览并保存报告。报告由你决定是否分享。
