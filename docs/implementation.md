# 架构与安全

## 桌面应用

| 组件 | 职责 |
| --- | --- |
| [Vue 前端](../src/) | 首页、图片工作台、接入和设置。通过领域 IPC 读取状态并提交操作 |
| [Tauri 应用](../src-tauri/) | 窗口、IPC、系统对话框、文件拖放、剪贴板和应用生命周期 |
| [Orbit Core](../crates/orbit-core/) | Panel 授权、Edge 请求、凭据、配置事务、图片和本地 SQLite |
| [凭据 helper](../crates/orbit-helper/) | 按已启用的客户端绑定交付凭据。候选包嵌入固定构建的 helper |

[IPC 类型](../src/shared/contracts.ts)只公开具体业务操作。前端取得脱敏视图和凭据引用，Rust 负责读取原始凭据、访问网络和写入文件。原生状态带有递增 revision，账户和节点切换后，前端拒绝旧上下文的异步回执。

## 登录与账户

Orbit 连接固定的 Orivelle Panel。桌面授权通过系统浏览器、绑定到回环的回调、单次授权码、state、PKCE 和 HTTPS 交换完成。取消授权会使迟到的回调失效。应用在读取凭据前校验 Panel origin。Panel 管理账户、权限、预算和消费，获准的 Edge 节点负责执行推理。测试编译可以使用隔离 Panel。

安装身份、备份加密密钥、账户会话和推理凭据分别保存在系统安全存储中。缺失或拒绝访问时相应操作失败。刷新令牌单次轮换，交换结果丢失或写入失败时需要重新授权。只读账户仍可查看账户和用量，自动取得推理凭据需要业务写权限。

退出会停用对应账户与 helper 绑定，并清理本地会话和推理凭据。若安全存储拒绝删除，凭据保持不可用并保留清理引用。删除本地连接和撤销服务端推理 key 是两个操作，客户端已缓存的凭据可能继续存在。安装身份和备份密钥供离线恢复使用，忘记安装会使关联备份失去恢复能力。 [桌面接入配置](desktop-configuration.md)

## 图片任务与账务

每个生成或编辑任务最多提交一次 JSON POST。完整请求（包括 base64）受节点准入上限和 64 MiB 上限中较小者约束，单图上限为 32 MiB。原生层校验真实 PNG、JPEG 或 WebP 格式并限制解码和磁盘占用。SQLite 保存任务元数据，图片单独落盘。

任务冻结账户、连接、节点、模型和输入快照。已发送的任务在取消、断线或超时后可能仍在服务端执行，客户端保留待确认状态。重试本地保存只处理已经收到的材料。复制和另存为在输出前重验账户、授权和文件内容。逐图删除只处理所选的本地记录。

Orbit 使用 `X-Orivelle-Request-ID` 关联 Panel 的执行和消费记录。执行状态、结果与结算分别显示，金额使用十进制字符串，保留真实零、未知和不同币种的区别。价格标明销售价、参考价或估价及其计量单位。

## 进程与更新

GUI 打开 SQLite 前获取进程锁。macOS 可以关闭窗口后保留进程，随后重新打开窗口。更新使用单独的维护和 helper 协调机制，启动时先处理未完成的更新事务。 [更新与恢复](update-recovery.md)
