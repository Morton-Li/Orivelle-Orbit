# 使用图片工作台

在 Orbit 中连接 Orivelle 账户并选择可用节点后，打开「图片工作台」。可用模型和生成选项取决于当前账户与节点。

## 生成或编辑图片

1. 在「创作」中选择模型，输入想要的画面或修改要求。
2. 如果要编辑已有图片，选择「添加参考图」或直接拖入图片。支持 PNG、JPEG 和 WebP。
3. 根据需要调整模型支持的选项，例如数量、尺寸或画质。选择「生成图片」或「编辑图片」，等待结果。

Orbit 会将提示词和所选参考图发送给 Orivelle 处理。收到的图片会保存在本机，可在「本地历史」中查看。

## 保存和再次使用

从结果预览或本地历史可以复制图片、另存为，或使用「再次编辑」将图片加入参考图。删除历史中的某张图片只清除对应的本地记录，服务端消费记录仍会保留。

如果收到结果后提示「本地保存失败」，请检查可用空间，再选择「重试本地保存」。这一步只重新保存已收到的结果。

## 查看状态和费用

任务的结果和费用分别显示。发送请求后，即使取消本地等待或网络中断，服务端仍可能完成并计费。若显示「结果待确认」或「费用待确认」，可先刷新账户信息并查看对应记录，再决定是否重新提交。

参考价用于估算，实际费用以 Orivelle 的消费记录为准。图片已保存时，费用也可能仍在确认中。
