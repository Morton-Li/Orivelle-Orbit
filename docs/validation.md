# 验证指南

按验证层记录提交 SHA、平台和工具链。测试、候选包检查和真实客户端操作分别记结果。执行入口见[构建与候选包](build-candidates.md)。

## 自动检查

| 验证层 | 覆盖范围 |
| --- | --- |
| 前端单元与构建 | 格式、lint、类型、账户隔离、配置预览和生产产物检查 |
| 浏览器流程 | Playwright 使用合成 IPC 检查页面交互、错误提示和状态切换 |
| 原生回归 | 使用测试目录和模拟凭据验证授权、配置 journal、图片和更新中断。真实系统操作的专项入口默认跳过 |
| 协议与授权 | [隔离网关](desktop-fake-gateway.md)验证合成 Responses 与 Messages 流程。[Panel 组件验收](../tests/acceptance/panel/README.md)需要单独的后端测试环境 |
| 候选产物 | 核对源码、平台架构、应用、嵌入 helper 和候选文件摘要 |

## 已记录的原生验证

截至 2026-11-06，原生实测来自 macOS arm64 上的历史候选。候选结果对应各自的源码与测试环境。

| 范围 | 结果与待验项 |
| --- | --- |
| macOS arm64 | 已构建并运行历史 `.app` 候选，覆盖未登录界面、诊断保存和窗口重开。另有合成条目的真实 Keychain 往返记录。配置最低版本 macOS 15.0 的实际运行仍待验证 |
| Claude Desktop 4.4212.0 | 候选 `137f5ed` 完成一次真实 Code Read，并通过界面保留偏好恢复接入，文件原权限另行补回。辅助角色测试在 helper 处超时 |
| Claude 映射凭据 | 后续候选在真实保存时返回安全存储错误，配置文件保持原样。后续修复验证了合成受保护条目的系统 ACL 元数据读回，实际 GUI 创建与固定 helper 非交互读取仍待联合验证 |
| Codex | 固定目录和配置接线有隔离回归，真实桌面配置往返、载入与推理仍待完成 |
| Windows x64 | 有原生构建和 NSIS 候选入口，尚无原生构建、运行和安装验收记录 |
| 签名与更新 | 有合成签名和恢复故障测试。正式签名、公证和真实安装、升级与回退仍待验证 |

## 发布前的原生验收

- 在计划支持的系统版本和架构上分别运行候选。记录首次启动、浏览器授权、凭据读写及拒绝、退出重登、窗口行为和本地文件操作。
- 按[桌面接入配置](desktop-configuration.md)逐个验证支持的客户端版本。分别记录保存与恢复、重启载入、所选模型的真实推理、流式和工具流程，以及辅助角色和错误路径。
- 验证图片选择和拖放、生成与编辑、本地保存和复制，并在取消或断线后核对请求和消费状态。
- 对拟分发的安装包记录实际签名、安装和卸载结果。启用自动更新前，另验签名拒绝、升级、异常中断和回退。保存脱敏结果与候选 manifest。
