# 图片工作台与本地历史验收

2026-11-13，本地 macOS arm64，分支 `fix/image-workbench-hint`。

## 已落实的功能

- 结果区移除等待说明、请求参数、上游返回参数、上游返回模型、服务端执行记录、结算状态和费用分项，仅保留模型显示名称和 Request ID。
- 创建图片任务时将目录中的显示名称保存为 `requested_model_label`，与任务、任务快照一起持久化；请求上游仍使用调用 ID。模型移出目录后，已有名称快照仍可读取。旧 JSON 记录缺少此字段时兼容读取；界面可回退到当前目录名称，找不到名称时不回退显示调用 ID。
- 删除“复用参数”的页面逻辑、TypeScript IPC 合同、原生命令注册、命令权限及 Rust 服务方法；删除已无调用方的参数摘要函数。再次编辑继续使用历史图片作为参考图。
- 结果预览使用解码所得宽高设置比例，图片放大也保持比例。历史缩略图恢复统一的 1.1:1 预览框，图片在框内按原始比例完整显示；横／方／竖图同时出现时卡片预览宽高一致。结果区域随内容收缩，历史卡片显示分辨率、格式、字节大小和生成时间。
- 原有请求参数、返回元数据和结算数据继续供生成、保存、恢复及用量链路使用。

## 预览

独立应用为 `target/debug/bundle/macos/Orbit Images Preview.app`，标识 `io.orivelle.orbit.images-preview`。入口、bridge 和演示素材均位于 `.cache/images-demo/`，运行数据位于项目 `runtime/` 中的独立目录；WebView 不持久化。普通生产构建不包含演示入口。

demo 使用合成账户和示例图片元数据，支持横图、方图、竖图及等待状态的样式预览；没有发送真实图片请求或产生实际消费。本轮没有修改系统设置、安装依赖、写入真实客户端配置或部署生产环境。
