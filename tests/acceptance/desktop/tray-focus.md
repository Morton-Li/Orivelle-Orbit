# 托盘面板初始焦点

验证日期：2026-11-16。分支：`fix/tray-panel-initial-focus`，基于 `develop` 的 `afc1265`，在独立 worktree 中实现。

## 行为

面板首次挂载及每次展开后，将焦点放在 `tabindex="-1"` 的面板容器。打开时没有默认选中的按钮，直接按 Enter 不会进入设置。键盘导航仍可进入设置和其他按钮，并显示原有焦点轮廓；普通状态刷新不会重置用户正在操作的焦点。

macOS WKWebView 补验发现，面板隐藏后再展开时，旧按钮可能已经不匹配 `:focus` 和 `:focus-visible`，计算样式与实际画面仍保留旧轮廓。增加 `button:not(:focus)` 的显式清除规则后，重开画面中的旧轮廓消失，主动键盘选中时的轮廓仍正常显示。

Windows 使用相同的面板组件和展开通知。窗口层面的 `set_focus` 继续保留，共享前端会重置 WebView 恢复的控件焦点。Windows 原生验收脚本增加面板初始焦点、无容器轮廓及 Tab 进入设置后的轮廓断言。

- macOS 原生引擎补验通过：项目内临时 AppKit 非激活 NSPanel、非持久 WKWebView 加载生产前端和未登录合成 IPC。首次打开、键盘选中后再打开时，面板容器获得焦点，所有按钮的计算轮廓均为 `none`。CUA 同时确认实际画面中无默认边框，Option+Tab 选中设置后边框正常出现，再次展开后边框消失。测试实例已退出。
